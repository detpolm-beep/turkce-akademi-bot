# 🇹🇷 Türkçe Akademi – Telegram Bot v2.0

> O'zbek tilida turk tilini o'rgatuvchi to'liq ishlaydigan Telegram bot

---

## ⚡ Tez Ishga Tushirish

```bash
pip install python-telegram-bot==20.7
python bot.py
```

Yoki `install_and_run.bat` faylini ikki marta bosing.
